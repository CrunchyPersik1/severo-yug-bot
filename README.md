# Северо-Юг — Telegram-бот: карточки, PvP, магазин и ивенты

Коллекционная игра в Telegram: карточки двух коллекций, PvP, кейсы, рулетки,
магазин с акциями, питомцы и зимний ивент «Санта Егор». Всё живёт в одном
FastAPI-сервисе: вебхук бота, мини-аппки и API на одном порту.

- Хостинг: **Render** (free web service), режим **webhook**
- Данные: внешняя **PostgreSQL (Supabase)** — persistent disk на free нет
- Стек: aiogram 3.15, FastAPI, asyncpg, чистый JS в страницах (без сборки)

## Что умеет бот

### Карточки
- Две коллекции: **7Г** (54 карты) и **7Д** (27 карт).
- 9 редкостей: редкий, сверхредкий, эпический, мифический, легендарный,
  секретный, ультимативный, ультралегендарный, учителя + **Премиум** для петов.
- «Северо-Юг» — карта раз в сутки (сброс 12:00 по ЕКБ), «западо-восток» —
  вторая коллекция, расход тот же.
- **Карта дня в приложении** (страница /drop): те же попытки, но с анимацией
  получения.

### Визуальный отклик
- Уровень эффектов зависит от редкости (0..5): редкая открывается просто,
  ультра — вспышка, лучи, тряска, корона.
- Ультимативная и ультра: карта **влетает из далека**, экран моргает белым,
  карта сияет переливающейся обводкой, из неё летят частицы цвета редкости,
  а снизу с двух сторон бьют **огонь и конфетти**.
- Анимация общая для кейсов, рулеток, карты дня, паков и питомника.
- Отключается в настройках приложения.

### PvP
- Вызов ответом на сообщение: «пвп». Каждый выбирает карту из своей коллекции.
- Бой идёт в одном сообщении, которое бот редактирует; 60 секунд без хода —
  автоудар, 3 подряд — техническое поражение.
- Победитель забирает 5% очков карты противника, карта получает +1 убийство.
- Античит: больше 5 боёв с одним игроком — стрик в ноль, штраф, бан PvP.

### Кейсы и рулетки
- Кейсы: 7Г, «7Д класс», «Ультра» (0.01% на ультру). Лента открытия — как в CS:
  4.5 секунды, резкий старт и плавное торможение.
- **Две рулетки**: классическая (очки, кейс, Дэниэл) и кристальная
  (кристаллы, кейсы, крупные очки).
- Обе крутят **до 3 спинов за раз**, пачка списывается целиком или не
  списывается вовсе.
- Вид переключается: **колесо или лента**, отдельно для каждой рулетки.
- Шансы всегда показаны списком под кнопкой.

### Магазин
- **Акции** (раздел «Акции»): 4 общих + 2 личных, смена каждые **4 дня**.
  Внутри — карты, кейсы, крутки, акции биржи, очки, Юги, кристаллы, оружие.
  Цена в одной валюте, скидка не больше 30% и не на всё.
- **Топ-паки** за кристаллы: 1–3 пака в ротации, каждый одноразовый.
- **Ежедневная награда** с джекпотом и множителем за серию 7 дней.
- **Кристаллы за очки**: 1 💎 = 55 555 очков (180 штук ≈ 10 млн).
- **Паки карточек**: одна случайная карта за пак, пачка из пяти дешевле.
- Учителя дня: шесть случайных на сутки, конкретного «под заказ» не купить.

### Питомцы
- **17 петов** редкости Премиум, у каждого своя пассивка.
- Яйцо «Коты» — 350 000 очков, инкубация **5 часов**, шансы:
  котость 0.01%, мэни 1%, патейто 25%, люси 73.99%.
- **Питомник**: сетка из 9 клеток, две прокачки — шанс редкого (+2%) и
  скорость (−10%), цена ×1.6 за уровень.
- Надеть можно одного пета. Подключены 10 пассивок из 17
  (Котость, Мэни, Рокки, Каспер, Люси, Яичко, Найда, Мишлен, Симона, Челси).

### Ивент «Санта Егор»
- Кнопка в хабе → сюжетка как визуальная новелла: портреты над хотбаром,
  11 реплик по нажатию, выбор из 4 решений только в конце.
- Решение меняет поведение Санты: скидку и частоту визитов (4/3 … 1/6 дней).
- **Роадмап из 6 эльфов** на пиксельной карте, сложность растёт.
- **Бой как в подземелье**: джойстик, лук, рывок, укрытия, аптечки,
  смена оружия (берётся из подземелья). С 3 уровня эльф стреляет веером из
  трёх стрел и раз в 15 секунд делает залп со всех сторон четырьмя волнами.
- **Магазин Санты**: 5 петов и яйцо, ротация; котость всегда в двух ценах —
  800 💎 и 100 млн очков.

### Остальное
- **Биржа**: живые курсы, пампы, дивиденды, оповещения о росте.
- **Юга-кликер**: 15 зданий, 104 апгрейда, престиж, древо 110 узлов.
- **Подземелье Тимура**: 10 локаций, мобы, кооп-босс по WebSocket, оружие,
  броня, НПС-квесты, чат, снег и погода.
- **Казино**, **кости**, **рулетка-стол**, **рынок**, **скупщик**,
  **апгрейдер**, **задания**, **мегаквест недели**, **рефералы**,
  **промокоды**, **профили**, **копилка**, **ивент «Звёздочка»**.

### Темы оформления
- Бесплатные: **Зима** (чёрный + голубой, снег), **Снег** (белый + голубой),
  **Мята**, **Терракота**.
- Платные: мел, астра, фиолетовый, хвоя, кислота, электрик, кровавый,
  ржавчина, графит.
- **Трофим** — личная чёрно-белая, выдаётся только админом.
- **Аурора** — VIP-тема с максимумом эффектов.
- В снежных темах летят хлопья, часть — размытые поверх экрана, на кнопках
  остаются снежинки.

## Деплой на Render

1. Supabase → Project Settings → Database → Connection string → **Session
   pooler** (IPv4): postgresql://postgres.REF:PASS@aws-0-REGION.pooler.supabase.com:5432/postgres
2. Render → New + → Blueprint → выбрать репозиторий (render.yaml в корне).
3. Переменные: **BOT_TOKEN**, **DATABASE_URL**; WEBHOOK_SECRET и
   WEBHOOK_TOKEN Render сгенерирует сам.
4. У @BotFather: Bot Settings → Group Privacy → **Turn off**, иначе бот не
   увидит сообщения в группах.
5. Вебхук ставится сам при старте из RENDER_EXTERNAL_URL.

Схема БД применяется при первом старте (schema.sql, идемпотентно).
GET / отдаёт 200 и JSON с версией сборки — годится для внешнего пингера
каждые 10 минут, чтобы сервис не засыпал (и Supabase не уходил в простой).

## Локальный запуск

    python -m venv .venv
    .venv\Scripts\activate        # Windows
    pip install -r requirements.txt
    cp .env.example .env           # BOT_TOKEN и DATABASE_URL
    uvicorn main:app --reload --port 8000

Без Telegram: **SKIP_TELEGRAM=1** — сервис поднимется сразу, не тратя
две минуты на ретраи get_me (с домашней сети api.telegram.org закрыт).

## Тесты

    pytest -q                      # 578 юнит-тестов, 29 скипаются без БД
    pytest -q tests                # то же по каталогу

    python scripts/check_coop.py   # живой прогон кооп-босса

В GitHub Actions (.github/workflows/ci.yml) тесты гоняются с настоящим
