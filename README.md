# Северо-Юг — Telegram-бот с карточками и PvP

Коллекционные карточки (32 шт.) + PvP-бои. Хостинг: **Render free Web Service**,
режим **webhook**, данные — во внешней **PostgreSQL (Supabase)**, потому что
persistent disk на free-тарифе нет.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `main.py` | FastAPI: `GET /` (health-check), вебхук, фоновый воркер таймаутов |
| `app/cards.py` | 32 карты: HP, ATK, способность, редкость, очки |
| `app/battle.py` | Боевой движок (чистые функции, без БД и Telegram) |
| `app/battle_service.py` | Транзакции боёв, выбор карт, таймауты, публикация сообщения |
| `app/db.py` | asyncpg-пул и все запросы |
| `app/gacha.py` | Веса редкостей и суточный сброс в 07:00 UTC |
| `app/handlers.py` | aiogram-роутеры |
| `app/render.py` | Тексты и инлайн-клавиатуры |
| `schema.sql` | Схема БД (применяется автоматически при старте) |

## Команды

- **«Северо-Юг»** (регистр и дефисы не важны) — выбить карту, 1 раз в сутки на пользователя.
  Сброс в **12:00 по ЕКБ** (07:00 UTC).
- **«пвп»** *ответом* на сообщение игрока — вызов на бой. Каждый выбирает карту из своей
  коллекции, бой идёт в одном сообщении, которое бот редактирует.
- `/my` — коллекция, `/top` — счёт по очкам, `/rating` — рейтинг PvP по победам,
  `/profile` — профиль (победы, поражения, убийства, очки), `/start` — справка.

## PvP-награды

- Победитель забирает **5% очков карты, которой воевал проигравший** (например, за
  Даниэля — 500 очков, за Олега — 12). Проигравший столько же теряет.
- Очки хранятся отдельным балансом (`players.bonus_points`) и прибавляются к сумме
  очков коллекции. Сами карты не портятся: их базовая стоимость неизменна.
- Карта победителя получает **+1 убийство**, это видно в `/my` и в профиле.
- Ничья ничего не меняет.

## Правила боя

- HP у каждой карты своё, базовый «Удар» тоже свой; урон **не зависит** от редкости и очков.
- У каждой карты уникальная способность с перезарядкой (щит, яд, оглушение, кража HP,
  уклонение, контрудар, лечение, немота, ослабление).
- Победитель — тот, у кого HP врага дойдёт до 0. 30 ходов суммарно — ничья.
- 60 секунд без нажатия — автоудар, 3 автоудара подряд — техническое поражение.
- Состояние боя хранится в БД: перезапуск Render бой не ломает.
- В PvP доступны **только карты из коллекции игрока**.

## Деплой на Render

1. Создай проект в Supabase и возьми **pooler**-строку подключения
   (Project Settings → Database → Connection string → **Session pooler**, IPv4):
   `postgresql://postgres.<ref>:<пароль>@aws-0-<регион>.pooler.supabase.com:5432/postgres`
2. Render → **New + → Blueprint** → выбери репозиторий (файл `render.yaml` уже в корне).
3. Впиши переменные:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `DATABASE_URL` — строка из Supabase
   - `WEBHOOK_SECRET` и `WEBHOOK_TOKEN` Render сгенерирует сам
4. Оффлайн в @BotFather: **Bot Settings → Group Privacy → Turn off**, иначе бот не увидит
   сообщения в группах.
5. Вебхук ставится автоматически при старте, из `RENDER_EXTERNAL_URL`. Руками ничего не нужно.

Схема БД создаётся при первом старте. `GET /` отдаёт `200` — подходит для внешнего пингера
каждые 10 минут, чтобы сервис не засыпал.

## Локальный запуск

```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env    # заполни BOT_TOKEN и DATABASE_URL
uvicorn main:app --reload --port 8000
```

Для локальной отладки без вебхука укажи `PUBLIC_URL` через туннель (ngrok/cloudflared) —
приложение само вызовет `setWebhook`.

## Тесты

```bash
pytest -q                      # юнит-тесты движка, карт и весов
TEST_DATABASE_URL=postgresql://postgres:postgres@localhost:5432/severo pytest -q
```

В GitHub Actions (`.github/workflows/ci.yml`) тесты гоняются вместе с настоящим Postgres.
## Эксплуатация: что может выключить бота

| Риск | Что делать |
| --- | --- |
| Render free засыпает через 15 минут простоя | Внешний пингер на `https://severo-yug-bot.onrender.com/` каждые 10 минут (UptimeRobot, cron-job.org). Обычный HTTP-монитор бесплатен и без лимитов. |
| Render free: 750 инстанс-часов в месяц на весь workspace | Держать разбуженным только этого бота. Если рядом крутятся другие бесплатные сервисы, бюджет общий: при перерасходе Render усыпляет free-сервисы до конца месяца. |
| Supabase free усыпляет проект после 7 дней без активности | `GET /` реально дёргает БД, поэтому пингер держит живой и её. |
| GitHub Actions на приватном репо: 2000 минут/мес | Шедулер «каждые 10 минут» съедает ~4300 минут/мес, поэтому GitHub-пингер здесь не используется. Варианты: внешний пингер или публичный репозиторий (тогда Actions бесплатны). |
| Вебхук при холодном старте | Ставится только если адрес изменился — очередь апдейтов не стирается. |

Токен бота, вебхук и данные в Supabase не истекают. После первого запуска
руками делать ничего не нужно: схема обновляется сама, карты перезаливаются
при старте.
## Рынок и улучшения

| Команда | Что делает |
| --- | --- |
| `/market` | Лоты с инлайн-кнопками: карта → статы, улучшения, продавец, «Купить» |
| `/sell #id цена` | Выставить карту (`#oleg` — копия из стака, `#12` — улучшенная) |
| `/mylots` | Свои лоты |
| `/changeprice id цена` | Переставить цену |
| `/upgrade #id` | Улучшить: выпадает аура, фон или эффект — навсегда |
| `/gift #id @игрок` | Подарить |
| `/rating [@игрок]` | Репутация торговца |
| `/pvprating` | Топ PvP по победам |

**Экономика.** Деньги — те же очки, что и ставки в PvP (`players.bonus_points`).
Покупка списывает, продажа зачисляет, **5% сделки сгорает**. Новый игрок начинает
с нуля и зарабатывает продажей карт.

**Цена.** `очки карты × коэффициент редкости × множитель улучшений`:

| Редкость | Коэф. | | Редкость | Коэф. |
| --- | --- | --- | --- | --- |
| Редкий | 1.0 | | Легендарный | 3.0 |
| Сверхредкий | 1.5 | | Секретный | 3.5 |
| Эпический | 2.0 | | Ультралегендарный | 4.0 |
| Мифический | 2.5 | | | |

**Репутация.** Старт 5.00. Лот дешевле 50% рыночной — `-0.5`, дешевле 20% — `-1.0`
и пометка 🚩. Честная сделка (≥80% рыночной) — `+0.1`, не больше `+1.0` в сутки.
При репутации ниже 1.50 выставлять лоты нельзя.

**Улучшения.** 10 аур (все статы), 10 фонов и 10 эффектов (один стат), все
равновероятны, бонусы бывают отрицательными. Один `/upgrade` занимает один
случайный свободный слот; всего их три, перебить нельзя. Улучшенная копия живёт
в таблице `inventory` со своим id, дубликаты без улучшений — стак в `collection`.

Бонусы работают и в бою: атака и HP множатся на проценты, защита снижает входящий
урон (не больше 60%).
## Рулетка и кейсы

Раз в сутки, после **20:00 по ЕКБ** (15:00 UTC — у «Северо-Юг» свой сброс в 07:00 UTC),
можно написать **«рулетка»** или \`/roulette\`. Призы:

| Приз | Шанс | Что даёт |
| --- | --- | --- |
| 💰 Очки | 89% | 100–5000 очков на баланс |
| 📦 Кейс | 10% | Предмет инвентаря, можно открыть или продать |
| 🏆 Даниэль | 1% | Главный приз рулетки, карта легендарной редкости |

**Кейс** открывается командой \`/case\`. Внутри — карта **эпической редкости и выше**:
эпическая 60%, мифическая 28%, легендарная 8%, секретная 3%, ультралегендарная 1%.
То есть из кейса реально может выпасть Валерия, просто шанс маленький.

Кейсы — полноценный товар: рыночная цена фиксирована в **5000 очков**, их можно
продавать (\`/sell #c3 цена\`), покупать, снимать с продажи и дарить.
### Профиль и чужие карты

\`/profile\` — свой профиль. \`/profile @игрок\` или ответом на сообщение — чужой.
В профиле кнопка **🃏 Мои карты**: список карт, где на каждую можно нажать и
посмотреть статы, способность, улучшения и число убийств этой картой.

Чужие профили, статы и карты открыты всем — смотреть можно сколько угодно.
Но продавать и улучшать чужие карты нельзя: в чужой карточке кнопок действий нет,
вместо них пометка «только просмотр».
## Админ-раздачи (для себя)

Локальный инструмент: подключается к базе напрямую, **VPN не нужен**, запускается
из cmd одной строкой. Строка подключения лежит в \`admin.local.bat\`, который
в \`.gitignore\` и в репозиторий не попадает.

| Команда | Что делает |
| --- | --- |
| \`severo limits 2 2\` | выдать всем по 2 карты и по 2 спина на сегодня |
| \`severo limits\` | вернуть обычные лимиты (1 и 1) и сбросить кулдауны |
| \`severo points 5000\` | накинуть всем по 5000 очков |
| \`severo case 1\` | выдать всем по кейсу |
| \`severo card daniel 1\` | выдать всем по карте (очки тоже начислятся) |
| \`severo status\` | сводка по базе |

Лимит попыток действует только на текущие сутки: при следующей смене дня он
вернётся к обычному (1 карта в 12:00 ЕКБ, 1 спин в 20:00 ЕКБ).
